# Arena Cars

Мобильная 3D-игра (вид сверху): машины на круглой арене выбивают друг друга в лаву.
Сейчас готов офлайн-режим: бой против 3 ботов, 4 арены, 5 способностей, гараж из 20 машин, монеты и опыт.

## Как получить APK
1. Создай репозиторий на GitHub и загрузи в него ВСЕ файлы из этой папки (включая скрытую папку `.github`).
2. Открой вкладку **Actions** → **Build APK** → **Run workflow** (или просто сделай push в ветку `main`).
3. Через 5-8 минут APK появится в **Releases** (справа на главной странице репозитория) — файл `ArenaCars.apk`.
4. Скачай его на телефон и установи (разреши установку из неизвестных источников).

## Управление
Джойстик в любом месте на своей половине экрана, кнопка способности с другой стороны. На компьютере: WASD/стрелки и пробел.

## Настройка баланса
- `src/store.js` — награды (`REWARD`) и опыт на уровень (`xpFor`)
- `src/cars.js` — характеристики и цены машин
- `src/sim.js` — физика, сила ударов (`KNOCK`), скорость сужения арены
